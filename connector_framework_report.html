1. 它解决什么问题

把「第三方智能体 / 服务端点」抽象为可插拔的 Connector，让 IRIS 能像调用工具一样把子问题 委派给外部 Agent（agent-to-agent 编排），或交给本系统内部的子 Agent。设计沿用现有 ToolRegistry 模式，但 Connector 面向更高层的「智能体能力」（一次 invoke = 一个完整子任务）。

2. 模块与职责

文件职责
app/connectors/base.pyBaseConnector(ABC) + ConnectorContext / ConnectorResult；async invoke + 同步 run() 桥接（独立线程 asyncio.run，兼容同步/异步上下文）
app/connectors/registry.pyConnectorRegistry + 单例 get_connector_registry() + reset_..._for_tests
app/connectors/registration.py配置驱动：type → 实现类路由（http_agent / openai_compatible / internal_subagent）
app/connectors/builtin/http_agent_connector.pyHttpAgentConnector：调外部 Agent 端点（OpenAI 兼容 / generic_json，httpx，best-effort）
app/connectors/builtin/internal_subagent_connector.pyInternalSubAgentConnector：复用本系统 LLM（get_llm）当子 Agent
app/tools/research_tools.py研究工具 delegate_to_connector（接入 researcher 节点）
app/core/config.py配置项 connectors: list[dict]；safe_summary 暴露 connectors_configured
tests/test_connectors.py13 用例

3. 如何接入第三方 Agent（无需改代码）

在 backend/.env 配置：

CONNECTORS=[{"name":"my_agent","type":"http_agent","config":{"base_url":"https://agent.example.com","api_key":"sk-xxx","model":"gpt-4o-mini"}}]

研究工具调用：{ "connector": "my_agent", "prompt": "...", "system_prompt": "..." }
